## Caso de uso
Catálogo de productos de una tienda e-commerce con variantes (talla/color), reseñas y estadísticas de ventas.

## Archivos
- `insert_100.js` → Crea la BD e inserta 100 documentos  
- `consultas.js` → Todas las consultas (básicas, filtros, agregación)  
- `productos_100.json` → Export listo para importar en MongoDB Compass  

## Cómo usar los archivo
1. Abre MongoDB Compass o mongo shell  
2. Ejecuta `insert_100.js`  
3. Ejecuta `consultas.js`  
¡Listo! Todo funciona a la perfeccion.
